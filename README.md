# Learn Japanese

A terminal-based flashcard/quiz script for practicing Japanese vocabulary — built and run directly from the Linux command line.

## What it does

Quizzes you on Japanese vocabulary (or kana/kanji) through the terminal, testing recall and tracking right/wrong answers as you go.

## Setup

No external dependencies beyond Python 3 (adjust this if you're using any libraries, e.g. for kana input or random selection from a JSON/CSV word list).

## Usage

```bash
python3 main.py
```

## Notes

- Vocabulary list is currently hardcoded/local — could be extended to load from an external file for easier editing.
- Built directly from the Linux terminal.
